# Roadmap

[English](https://github.com/JokerJohn/Manual_Calibration_Tools/wiki/Roadmap) | [中文](https://github.com/JokerJohn/Manual_Calibration_Tools/wiki/Roadmap-zh)

## v1: FAST-Calib Offline GUI

Status: private beta / documentation preview.

Delivered direction:

- prepared image/PCD sample input;
- camera and LiDAR feature review;
- batch diagnostics;
- SVD solve for `T_cam_lidar`;
- auditable reports and visual outputs.

## v1.x: Packaging

Planned:

- public source package;
- reproducible environment files;
- example dataset guidance;
- screenshots or demo video when safe to publish;
- import and documentation checks.

## v2: Calibration Board Profiles

Planned:

- named target profiles beyond the current FAST-Calib board;
- configurable board geometry;
- clearer detector/solver/export profile separation.

## v3: Broader Calibration Tasks

Planned:

- more camera-LiDAR calibration variants;
- future multi-camera or multi-LiDAR workflows;
- project/session management;
- downstream export profiles.
